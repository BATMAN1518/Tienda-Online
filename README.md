# Tienda Online · NÓMADA

Tienda web de 4 productos creada con el método de la skill `tienda-shopify-v3.zip`.

- `web/index.html` — portada con todos los productos
- `web/producto-*.html` — una página personalizada (colores, tipografía y bloques propios) por producto
- `web/js/productos.js` — **aquí se cambian precios, variantes y fotos**
- Carrito lateral con envío gratis desde 50 €, guardado en el navegador

Ver en local: `cd web && python3 -m http.server 8080` → http://localhost:8080

Se puede publicar gratis tal cual en GitHub Pages, Netlify o Vercel (carpeta `web/`).

(El simulador `simuladorprueba.py` es un proyecto independiente de Streamlit.)
